Printer

Printing through the RawBT app. One-time setup:

  1. Install RawBT from the Play Store.
  2. Pair the printer in Android Settings → Bluetooth (skip if GrabMerchant already uses it).
  3. In RawBT settings: Connection method = Bluetooth → pick your printer. Printer driver = ESC/POS. Paper = 58mm.
  4. Close GrabMerchant (only one app can use the printer at a time), then tap Test print below.
Get RawBT on Play Store

Connected but nothing prints?

Tap Find working channel. The printer prints "CHANNEL n WORKS" for each channel that works. Then tap that channel below.
